# 美赛 (MCM/ICM) 备赛资料仓库

[English Version (英文版本)](../README.md)

---

## 📌 项目介绍

本仓库用于存放和整理 **美国大学生数学建模竞赛（MCM/ICM）** 的备赛资料。

为了便于团队协作与高效备赛，仓库主要针对团队的三个核心角色划分了三个板块：

- **[`coding/`](../coding/)**：**代码手** 备赛资料（常用算法实现、代码模板、数据处理脚本等）。
- **[`math/`](../math/)**：**建模手** 备赛资料（数学模型、算法原理、参考论文、解题方法论等）。
- **[`writing/`](../writing/)**：**论文手** 备赛资料（论文模板、LaTeX/Word 排版资源、图表规范、写作指南等）。

---
