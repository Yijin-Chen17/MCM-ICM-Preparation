## 📌 Overview

This repository is dedicated to storing and organizing preparation materials for the **MCM/ICM (Mathematical Contest in Modeling / Interdisciplinary Contest in Modeling)**.

To facilitate efficient teamwork and structured preparation, the repository is organized around the three core roles of the team:

- **[`coding/`](coding/)**: Resources, code templates, algorithms, and data processing scripts for the **Coder** (代码手).
- **[`math/`](math/)**: Mathematical modeling resources, algorithms, literature, and methodology notes for the **Modeler** (建模手).
- **[`writing/`](writing/)**: Paper templates (LaTeX / Word), writing guidelines, visualization standards, and reference materials for the **Writer** (论文手).
